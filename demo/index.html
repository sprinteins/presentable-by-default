What is classless CSS?

Plain HTML elements are styled directly. Classes are optional helpers.

How do themes work?

Set data-theme on <html> or on any element for a scoped theme.

Can I add my own theme?

Copy src/themes/_template.css, fill in the tokens, register it, run the build.
